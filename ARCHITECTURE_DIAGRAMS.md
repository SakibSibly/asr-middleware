## 5. API Request Flow

```

  │                         │                     │                 │                 │
  │  POST /meetings/        │                     │                 │                 │
  ├────────────────────────>│                     │                 │                 │
  │                         │  Create Meeting     │                 │                 │
  │                         ├────────────────────────────────────────────────────────>│
  │                         │                     │                 │     Store       │
  │  201 Created            │<────────────────────────────────────────────────────────┤
  │<────────────────────────┤                     │                 │                 │
  │  {id: "...", ...}       │                     │                 │                 │
  │                         │                     │                 │                 │
  │  POST /upload-audio/    │                     │                 │                 │
  ├────────────────────────>│                     │                 │                 │
  │                         │  Store File         │                 │                 │
  │                         ├──> S3 Upload        │                 │                 │
  │  200 OK                 │                     │                 │                 │
  │<────────────────────────┤                     │                 │                 │
  │                         │                     │                 │                 │
  │  POST /process/         │                     │                 │                 │
  ├────────────────────────>│                     │                 │                 │
  │                         │  Queue Task         │                 │                 │
  │                         ├────────────────────>│                 │                 │
  │  202 Accepted           │                     │  Pick Task      │                 │
  │<────────────────────────┤                     ├────────────────>│                 │

  ├────────────────────────>│                     │                 │  Save Result    │

  │                         ├────────────────────────────────────────────────────────>│
  │  200 OK                 │<────────────────────────────────────────────────────────┤
  │<────────────────────────┤                     │                 │                 │

  │                         │                     │                 │                 │
  │  ... wait ...           │                     │                 │                 │
  │                         │                     │                 │  Task Complete  │
  │                         │                     │                 ├────────────────>│
  │                         │                     │                 │                 │
```
